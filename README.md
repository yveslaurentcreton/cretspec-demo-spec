# Atlas specification

The specification of the fictional Atlas project. It demonstrates [CretSpec](https://github.com/yveslaurentcreton/CretSpec): clone this one repository and get the whole project.

```sh
cspec project clone https://github.com/yveslaurentcreton/cretspec-demo-spec.git
```

You get one folder:

```text
Atlas/
├── AGENTS.md                    generated: what is here and which rules apply
├── cretspec-demo-spec/          this repository
├── cretspec-demo-app/           the code
└── cretspec-demo-guidelines/    shared AI guidelines
```

`project.json` names the other two repositories. `spec/` holds the project's rules and skills. See the [quick start](https://yveslaurentcreton.github.io/CretSpec/start/quickstart/).
